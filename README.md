# 🏥 appProvaA1Hospital

Aplicativo desenvolvido como parte das aulas de **Programação para Dispositivos Móveis**, utilizando **.NET MAUI**. O projeto está em desenvolvimento e tem como objetivo colocar em prática os conhecimentos adquiridos durante a disciplina.

## 📱 Sobre o projeto

O **appProvaA1Hospital** é um projeto acadêmico relacionado ao contexto hospitalar. Sua implementação está sendo construída gradualmente durante as aulas, com funcionalidades e melhorias adicionadas ao longo do desenvolvimento.

> 🚧 **Status:** Em desenvolvimento — as funcionalidades ainda podem mudar.

## 🛠️ Tecnologias utilizadas

- **C#**
- **.NET MAUI**
- **Visual Studio**

## 🎯 Objetivos de aprendizagem

- Praticar o desenvolvimento de aplicações para dispositivos móveis com .NET MAUI.
- Aplicar conceitos de programação com C#.
- Conhecer a estrutura de um projeto multiplataforma.
- Desenvolver funcionalidades de forma incremental durante a disciplina.

## ▶️ Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/phsmontheiro-glitch/appProvaA1Hospital.git
   ```

2. Extraia o arquivo `appProvaA1Hospital.zip` incluído no repositório.
3. Abra o projeto no Visual Studio com a carga de trabalho do **.NET MAUI** instalada.
4. Restaure as dependências, selecione um emulador ou dispositivo compatível e execute o aplicativo.

> Os passos podem variar conforme a estrutura atual do projeto e a plataforma escolhida.

## 🚧 Status do desenvolvimento

O projeto continua em desenvolvimento e será atualizado conforme o avanço das aulas e a implementação de novas funcionalidades.
